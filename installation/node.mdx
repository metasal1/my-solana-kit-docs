title: Node
description: Install @solana/kit
---

```bash
npm install @solana/kit
```

`@solana/kit` 8.6.0 is the current release. It re-exports the public modules, so most snippets on this site only add the program client they call (`@solana-program/system`, `@solana-program/token`, and so on). Those clients peer-depend on `@solana/kit` ^8.5.0.

The modules live in the [Kit monorepo](https://github.com/anza-xyz/kit/tree/main/packages).

You can still install one module when you want a smaller dependency.

### Accounts
```bash
npm install @solana/accounts
```
### Codecs
```bash
npm install @solana/codecs
```
