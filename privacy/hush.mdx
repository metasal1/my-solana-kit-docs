Hush Protocol is a **Zcash-inspired privacy layer** on Solana, developed by [Zenrock](https://zenrocklabs.io). It launched in February 2026 and enables shielded deposits, transfers, and withdrawals for SOL and SPL tokens. Deposited SOL is automatically converted to jitoSOL, distributing staking yield and MEV to users.

> **Note:** Hush Protocol is a UI-first product. An official developer SDK was not publicly available as of early 2026. The examples below reflect the expected integration pattern when an SDK ships.

## Features

- Shielded deposits and withdrawals (SOL → jitoSOL in the pool)
- Private transfers between shielded addresses
- One-time addresses for recipient privacy
- Built on Solana's Token-2022 with ZK proofs

## Expected SDK Usage (when available)

```bash
npm install @hush/solana-sdk
```

```tsx
// Expected pattern (not yet released)
import { HushClient } from "@hush/solana-sdk";
import { createSolanaRpc, createKeyPairSignerFromBytes } from "@solana/kit";
import wallet from "../wallet.json";

const rpc = createSolanaRpc("https://api.mainnet-beta.solana.com");
const payer = await createKeyPairSignerFromBytes(new Uint8Array(wallet));

const hush = new HushClient({ rpc });

// Deposit SOL into shielded pool
const depositTx = await hush.deposit({
  signer: payer,
  amount: 1_000_000_000n, // 1 SOL in lamports
});
console.log("Deposit tx:", depositTx);

// Transfer to a shielded address
const transferTx = await hush.transfer({
  signer: payer,
  recipient: "shielded_address_here",
  amount: 500_000_000n,
});
console.log("Transfer tx:", transferTx);
```
