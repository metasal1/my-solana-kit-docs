[Reclaim Protocol](https://reclaimprotocol.org) generates **zero-knowledge proofs of any HTTPS web session** — proving you own an account, have a balance, or meet criteria on any website, without revealing the raw data.

> Not Solana-specific, but commonly used in Solana apps for off-chain attestations and gated access.

## Installation

```bash
npm install @reclaimprotocol/js-sdk
```

## Basic Usage

```ts
import { ReclaimProofRequest } from "@reclaimprotocol/js-sdk";

// Get your App ID + Secret from https://dev.reclaimprotocol.org
const APP_ID = "your_app_id";
const APP_SECRET = "your_app_secret";

// Provider ID from Reclaim's catalog (e.g. GitHub username, Twitter followers, etc.)
const PROVIDER_ID = "6d3f6753-7ee6-49ee-a545-62f1b1822ae5"; // GitHub username

const reclaimProofRequest = await ReclaimProofRequest.init(
  APP_ID,
  APP_SECRET,
  PROVIDER_ID
);

// Generate a URL the user opens to produce the proof
const requestUrl = await reclaimProofRequest.getRequestUrl();
console.log("Open this URL to generate a proof:", requestUrl);

// Poll for the proof (or use a callback URL in production)
const statusUrl = reclaimProofRequest.getStatusUrl();
console.log("Status URL:", statusUrl);

await reclaimProofRequest.startSession({
  onSuccess: (proofs) => {
    console.log("Proof received:", proofs);
    // Use proof on-chain or in your app
  },
  onFailure: (error) => {
    console.error("Proof failed:", error);
  },
});
```
