> **Status:** Range Protocol is an early-stage project. No public npm SDK has been released as of early 2026.

Range proofs allow a prover to demonstrate that a secret value lies within a range (e.g. a balance is positive, or a transaction amount is non-negative) **without revealing the actual value**. They are a fundamental building block of privacy-preserving DeFi.

## Solana Native Range Proofs

Solana's Token-2022 Confidential Transfers extension uses **Bulletproofs** (a range proof system) natively to validate encrypted token amounts without revealing them.

```tsx
import { createSolanaRpc } from "@solana/kit";

const rpc = createSolanaRpc("https://api.devnet.solana.com");

// Confidential Transfers uses range proofs under the hood.
// See: /token-extensions/confidential-transfers
// The Token-2022 program handles ZK proof generation and verification on-chain.

const info = await rpc.getAccountInfo(
  "TokenzQdBNbLqP5VEhdkAS6EPFLC1PHnBqCXEpPxuEb" // Token-2022 program
).send();
console.log("Token-2022 program:", info.value?.owner);
```

## Manual Range Proof (using @solana/zk-token-proof-instructions)

```tsx
import { createSolanaRpc } from "@solana/kit";
// Range proofs for Confidential Transfers are handled by:
// @solana/zk-token-proof-instructions (part of the Token-2022 SDK)
//
// Example: generating a range proof when depositing into a confidential balance
// is handled automatically by the spl-token-confidential-transfer CLI and SDK.
```

## Alternatives

For production range proofs on Solana today:

- **[Confidential Transfers](/token-extensions/confidential-transfers)** — native Token-2022, uses Bulletproofs
- **[Light Protocol](/privacy/light-protocol)** — ZK compression with validity proofs
- **[Aztec](/privacy/aztec)** — full ZK smart contracts on Ethereum (not Solana)
