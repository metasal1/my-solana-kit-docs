> **Status:** Dark Protocol is an early-stage Solana privacy project. No official developer SDK has been publicly released as of early 2026. The information below reflects what is known from community sources.

Dark Protocol is a Solana-based privacy project (ticker: `$DARK`) aimed at providing anonymous transfers, similar to Monero-style privacy on Solana.

## Current State

- No official npm SDK available
- No public documentation or developer portal
- Community-discussed project — verify legitimacy before use

## DarkFi (Separate Project)

[DarkFi](https://dark.fi) is a separate L1 blockchain for anonymous engineering, built by Amir Taaki. It is **not** related to the Solana Dark Protocol and runs its own chain with a ZK assembly language.
