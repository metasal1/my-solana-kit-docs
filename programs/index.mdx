# New Location

```bash
@solana-program/{name}

e.g. @solana-program/stake
```
# Old Location
```bash
@solana/{name}

e.g. @solana/stake-program
```

The program repositories are at [github.com/solana-program](https://github.com/solana-program). These JavaScript clients are published and peer-depend on `@solana/kit` ^8.5.0. Associated token accounts are exported from `@solana-program/token` and `@solana-program/token-2022`. Several other repositories in that org do not publish a JavaScript client.

| Package Name | Description |
|-------------|-------------|
| @solana-program/address-lookup-table | Address lookup tables |
| @solana-program/compute-budget | Compute budget |
| @solana-program/loader-v3 | BPF loader |
| @solana-program/memo | Memo program |
| @solana-program/program-metadata | Program metadata |
| @solana-program/record | Record program |
| @solana-program/stake | Stake program |
| @solana-program/system | System program |
| @solana-program/token | SPL Token, including associated token accounts |
| @solana-program/token-2022 | Token Extensions |
| @solana-program/token-wrap | Token wrap |
| @solana-program/zk-elgamal-proof | ZK ElGamal proof |
