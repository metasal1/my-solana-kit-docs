title: Load Keypair
description: load a wallet from the filesystem
---

## New Way

`createKeyPairSignerFromBytes` returns a signer. `createKeyPairFromBytes` returns only the `CryptoKeyPair` and cannot pay fees.

```js
import { createKeyPairSignerFromBytes } from '@solana/kit'
import walletSecret from './wallet.json'

const main = async () => {
    const wallet = await createKeyPairSignerFromBytes(new Uint8Array(walletSecret));
    console.log("wallet: ", wallet.address);
}

main();
```

## Old Way

```js
import { Keypair } from "@solana/web3.js";
import walletSecret from './wallet.json'

const wallet = Keypair.fromSecretKey(new Uint8Array(walletSecret));
console.log(wallet.publicKey.toBase58());
```
