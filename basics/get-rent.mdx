---

The local `getMinimumBalanceForRentExemption` helper was removed in `@solana/kit` 7. Ask the cluster. The size is a `bigint`, and the result is lamports.

```js
import { createSolanaRpc } from "@solana/kit";

const rpc = createSolanaRpc('https://api.mainnet-beta.solana.com');
const rent = await rpc.getMinimumBalanceForRentExemption(0n).send();

console.log(rent);
```
